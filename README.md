# EL AMAL

English and Arabic industrial product catalogue, quotation requests, and protected stock administration.

## Current state

Discovery checkpoint, 17 September 2026. The supplied proposal has been read and mapped to a build brief. Application code, dependencies, database, and deployment have not been created yet.

- [Kickoff brief and implementation checklist](docs/kickoff-2026-09-17.md)
- [Current progress and next decisions](PROGRESS.md)

The planned architecture is Next.js with TypeScript, Payload CMS, and PostgreSQL. Exact compatible versions must be verified against official documentation before installation. This repository has no run command until the application foundation is implemented.

Real catalogue specifications, brand assets, stock counts, and credentials must not be invented. Source documents and commercial proposal text are kept outside version control. Public catalogue publication requires reviewed bilingual content and asset rights.
